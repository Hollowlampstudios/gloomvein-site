Rebirth and difficulty

Beat Cinderheart and you can Rebirth: the world ends and you start a new one with any class and any difficulty you have unlocked.

  • You keep: gems, gem shop upgrades, boost time left, cosmetics, achievements, Core Shards, the Core Tree, Class Mastery and your hero's name.
  • You start again: coins, items, gear, crew, depth, spells and minions.

Core Shards

A Rebirth pays floor(sqrt(lifetime coins / 4,000) x the difficulty's shard multiplier) Core Shards, where lifetime coins are all the coins this world has earned.

Class Mastery

Each time a class beats Cinderheart and you Rebirth, that class gains a Mastery level (max 5). The bonus applies whenever you play that class.

ClassBonus
Melee+1% lifesteal per level
Ranged+4% arrow save per level
Magic+5% spell power per level
Summoner+5% minion power per level

Difficulty

A harder difficulty unlocks when you beat Cinderheart on the one before it. A boss's attack rises by only half of the difficulty's enemy attack increase.
