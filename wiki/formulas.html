Formulas

Every rule the game uses, with its exact numbers.

Enemies

health = base health x layer strength x (1 + depth/5)^1.15 x wave x night x elite x event x difficulty

attack = base attack x pressure(depth) x layer strength x (1 + depth/30)^1 x wave x night x elite x event x difficulty

coins = round(base coins x (1 + depth/5)^1.15 x night x elite x event x difficulty), at least 1.

  • Pressure is x1.5 at the surface, easing to x1.3 at depth 240.
  • Wave: 1 + 0.03 x (Elite Waves beaten), at most 9 steps.
  • Night (full night): health x1.2, attack x1.15, coins x1.5, drops x1.5, spawns 30% faster.
  • Elite: health x1.8, attack x1.3, coins x3, drops x2.
  • Drops: each drop rolls its chance x (night x elite x event x difficulty) x (1 + drop chance bonus), capped at 100%.

Bosses

boss health = base x difficulty boss health; boss attack = base x 1.6 x (1 + (difficulty enemy attack - 1) / 2). After its enrage time, attack = that x (1 + enrage rate x seconds past it). Helpers have 25% of the same enemy's health and 60% of its attack at that depth, and drop nothing.

Your hero

  • attack = (class base + gear + sets + potions) x class tier multiplier x (1 + Core Tree attack %)
  • health = (class base + gear + sets + potions) x (1 + Core Tree health %) x class tier health multiplier
  • attack interval = class base / (1 + attack speed), never below 0.25 s.
  • tap damage = attack x class tap multiplier.
  • Crit: chance capped at 75%, x2 damage. Minion and tower hits never crit.
  • Damage taken: x 10 / (10 + defense), then the Arcane ward and class shields.
  • Health regeneration: 1.5% of max health per second plus class and gear regen, at 60% speed while enemies are hitting you.
  • Ore luck is capped at 100%, arrow save at 80% and lifesteal at 50%.
